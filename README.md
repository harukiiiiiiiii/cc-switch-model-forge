# Model Forge · cc-switch 模型目录工作台

一个纯前端、离线可用的可视化配置界面，用于查看和编辑 cc-switch 使用的模型目录
（`cc-switch-model-catalog.json`，即 `{"models": [...]}` 结构）。

## 在线使用

GitHub Pages：<https://harukiiiiiiiii.github.io/cc-switch-model-forge/>

仓库通过 GitHub Actions 持续检查并发布：提交和 Pull Request 会执行 JavaScript
语法、静态文件引用和 HTTP 冒烟测试；`main` 分支检查通过后自动部署到 GitHub Pages。

## 打开方式

直接用浏览器打开 `index.html` 即可。数据已经内嵌在 `catalog-data.js` 中，不需要
本地服务器，也不依赖网络。

## 功能

- 模型侧栏：按模型家族分组，支持搜索和可见性筛选，卡片显示上下文、推理档数、优先级等关键指标，并标注相对目录基线的修改。
- 全目录批量修正：顶部可把多智能体版本、默认推理等级、搜索能力、上下文窗口等常用标量字段统一应用到全部模型；应用前显示影响数量、检查目录有效性，并可作为一次操作整体撤销。
- 模块化编辑器：基础信息、推理与能力、上下文与运行、指令与权限四个模块全部平铺展示，无需手动展开即可看到所有参数。顶部模块导航可直达长表单中的任意模块，并支持字段搜索和「只看修改」。
- 字段级恢复：每个已修改字段都会即时标记，可单独恢复到最近一次导入或内置目录的基线值；恢复能力在刷新后仍保留。
- 全部字段模式：打开「全部字段」开关可查看并添加 schema 中尚未出现的字段；导入目录中的未知顶层字段会显示在「扩展字段」模块中，可查看、编辑和删除。
- 目录总览：全部模型的横向对比表，点击表头可排序。
- 字段地图：所有可编辑字段的类型、可空性和模型覆盖数一览，点击字段可跳转到编辑器对应位置。
- 可见性开关：模型卡片和编辑区标题处都有「可见/隐藏」按钮，点击即可切换，无需进入表单修改。
- 导入 / 导出 / 恢复基线：导入会先完成结构校验再一次性替换目录；导出前会阻止无效 JSON 和配置错误，也可按 `Ctrl+S` 快速导出。恢复基线会回到最近一次成功导入的目录，未导入过时使用内置目录。
- 自动保存与撤销：所有字段编辑实时写入浏览器本地存储，顶部显示保存状态，刷新页面不丢失；支持顶部按钮以及 `Ctrl+Z` / `Ctrl+Y` 撤销和重做。
- 模型管理：支持新建、复制、删除模型；复制时自动生成唯一 slug 和优先级。
- 配置校验：检查 slug 合法性与唯一性、字段类型、数组结构、上下文范围、推理等级和服务层级关联；错误可点击定位，并直接关联到对应输入框。
- 键盘操作：标签页支持方向键切换，模型列表、字段地图、总览模型入口和全部字段开关均可使用键盘操作。
